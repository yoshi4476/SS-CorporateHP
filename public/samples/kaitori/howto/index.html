買取方法（店頭・宅配・LINE査定）

当社の買取方法は「店頭買取」「宅配買取」「LINE査定」の3つです。すぐに現金化したい方は店頭、来店が難しい方は宅配、まず金額の目安を知りたい方はLINE査定が向いています。いずれも査定料・手数料は無料で、買取には古物営業法にもとづく本人確認書類が必要です。

3つの買取方法から、ご都合に合わせてお選びください

当社の2店舗（〇〇〇〇A 心斎橋店、〇〇〇〇B）では、「店頭買取」「宅配買取」「LINE査定」の3つの方法をご用意しています。どの方法でも査定料・手数料は無料で、金額にご納得いただけない場合のキャンセルも無料です。

「今日中に現金にしたい」なら店頭買取、「お店に行く時間がない」「品物が多くて運べない」なら宅配買取、「売るかどうか決める前に目安を知りたい」ならLINE査定がおすすめです。

店頭買取の流れ：その場で現金をお受け取りいただけます

店頭買取は、お品物をお持ちいただき、その場で査定・お支払いまで完了する方法です。ご予約は不要です。お急ぎの場合は、事前にお品物の詳細をお電話でお知らせいただくと、よりスムーズにご案内できます。

  1. ご来店お売りになりたいお品物と、本人確認書類をお持ちください。〇〇〇〇A 心斎橋店は24時間営業（お盆・年末年始を除く）です。
  2. 鑑定士による査定お客様の目の前で、鑑定士が1点ずつ丁寧に査定します。〇〇〇〇A 心斎橋店では、プライバシーに配慮した個別ブースで査定を行います。
  3. 買取価格のご提示お品物の人気・状態・当日の相場をもとに買取金額をご提示し、査定の内容もご説明します。
  4. ご成約・お支払い金額にご納得いただけましたら、その場で現金でお支払いします。ご納得いただけない場合はキャンセルでき、キャンセル料はかかりません。

宅配買取の流れ：ご自宅から送るだけ

宅配買取は、ご自宅からお品物を送っていただき、当店で査定・お振込みを行う方法です。送料は当店が全額負担し、梱包キットも無料でお送りします。査定の内容は店頭買取と同じです。

  1. お申込み必ず事前に、お電話またはLINEでお申込みください。〇〇〇〇A 心斎橋店：TEL 000-0000-0000／LINE @〇〇〇〇。
  2. 梱包キットの受け取り・発送届いた梱包キットに、本人確認書類のコピーとお品物を入れ、着払いでお送りください。隙間には新聞紙などのクッション材を入れ、破損しないように梱包してください。
  3. 査定お品物が当店に到着しだい査定し、査定額をお電話またはLINEでご連絡します。
  4. お支払い査定額にご納得いただけましたら、ご指定の口座にお振込みします。銀行の営業時間外の場合は、翌営業日のお振込みとなります。

宅配買取のご注意

〇〇〇〇A 心斎橋店の宅配買取は、当店の梱包キット以外でお送りいただいたお品物は受け付けておりません。キャンセルの場合は、当店の負担でご返送します（キャンセル料・返送手数料は無料）。

〇〇〇〇Bの宅配買取も全国送料無料で承っています。お申込み方法（電話・LINE・フォーム）、梱包キットの有無、お振込みまでの日数は【要確認】です。非対面での取引となるため、古物営業法施行規則に定める本人確認の方法（本人確認書類のコピーに加えて必要となる手続き）も【要確認】です。

このサイトのお問い合わせフォームからも、宅配買取のお申込みを受け付けています。

LINE査定の流れ：写真を送るだけで目安が分かります

LINE査定の金額について

LINE査定でお伝えする金額は、写真をもとにした想定額です。実物を確認したうえで最終的な買取価格が決まるため、状態によっては金額が変わることがあります。友だち追加の要否は店舗ページで表記が異なるため【要確認】です。

LINE査定の撮影ポイント

写真のポイントを押さえていただくと、より正確な査定額をお伝えできます。まずは、すべてのお品物に共通する4つのポイントをご確認ください。

  1. ピントを合わせるなるべく明るい場所で撮影し、ピントが合っているか確認してください。暗い写真やぼやけた写真は、査定に時間がかかります。
  2. 全体を写すお品物の全体が画面いっぱいに写るように撮影してください。見切れていると査定が難しくなります。
  3. 複数枚撮る角度を変えた写真や、タグ・刻印の部分も撮影してください。枚数が多いほど、正確な金額をお伝えしやすくなります。
  4. 付属品も撮る保証書やギャランティカードは、「商品名」や「型番」が読めるように撮影してください。

店頭買取に予約は必要ですか？

いいえ、ご予約は不要です。営業時間内であれば、ご来店いただいてすぐに査定します。お急ぎの場合は、事前にお電話でお品物の詳細をお知らせいただくとスムーズです。

宅配買取で、査定額に納得できなかった場合はどうなりますか？

キャンセルしていただけます。キャンセル料・返送料はかからず、当店の負担でお品物をご返送します。

LINE査定の金額で必ず買い取ってもらえますか？

LINE査定の金額は、写真をもとにした想定額です。実物を拝見したうえで最終的な買取価格を決定するため、状態によっては金額が変わる場合があります。写真を複数の角度から送っていただくと、より正確な金額をお伝えできます。
